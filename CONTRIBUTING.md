# Contribuição

Este repositório é o portfólio pessoal de Eduardo Melo. Correções objetivas são bem-vindas por pull request.

## Fluxo de trabalho

1. crie uma branch curta a partir de `main`, como `fix/contraste` ou `feat/novo-case`;
2. instale as dependências com `npm ci`;
3. execute `npm run check` antes de enviar a alteração;
4. para mudanças de interface, execute também `npm run test:e2e`;
5. descreva no pull request o problema, a solução e a evidência de validação.

Não inclua credenciais, dados pessoais, conteúdo confidencial nem métricas sem fonte verificável.
